# NEXORA — Startup · AI Research

A standalone, responsive one-page website inspired by clean AI research and startup ecosystem websites. All styling and JavaScript are inside `index.html`; the logo is embedded, so there are no asset folders or dependencies.

## Publish on GitHub + Vercel from a phone
1. Extract the ZIP.
2. Upload `index.html` to the root of a GitHub repository (README.md is optional).
3. In Vercel, import the repository.
4. Choose **Other** / static site if prompted. No build command is required; leave the output directory empty unless Vercel requests `.`.

The contact button currently opens the visitor's email app to `hello@nexora.tech`. Replace that address in `index.html` with your real company email before launch.
